# Projeto 01 — Testes de Formulário de Cadastro

## Objetivo
Verificar o comportamento de um formulário de cadastro, avaliando entradas válidas e inválidas.

## Escopo dos testes
- Preenchimento de campos obrigatórios
- Validação de formato de e-mail
- Validação de senha
- Confirmação de senha
- Comportamento diante de dados inválidos

## Ferramentas
- GitHub para documentação e versionamento
- Testes manuais
